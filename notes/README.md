# Learning Notes

This directory contains research and concept notes produced while studying
reliable AI systems.

## Note Types

- Concept notes
- Paper and article notes
- System and architecture studies
- Framework comparisons

## Naming

Use lowercase kebab-case names:

`durable-execution.md`
`react-agent-pattern.md`

## Completion Criteria

A completed note should include:

1. The question being studied
2. A concise explanation in my own words
3. Important concepts and terminology
4. Tradeoffs or failure modes
5. Connections to the hands-on labs
6. Public sources and attribution
7. Remaining questions
