# reliable-ai-systems-lab

Hands-on experiments in reliable AI Systems: agent runtimes, durable workflows, evaluation, observability, sandboxing, and ML infrastructure.

This repository documents my hands-on learning as a distributed-systems engineer exploring reliable AI infrastructure, agent systems, and ML platforms.

Reliable AI Systems Lab is a collection of hands-on studies, implementations, and experiments exploring how AI systems can be made dependable in practice. The repository covers tool-using agent runtimes, durable execution, failure recovery, evaluation, observability, secure execution, platform operations, and ML-serving tradeoffs.

Each topic progresses from foundational research to a working implementation, failure testing, measurement, and written analysis. The goal is not to build another general-purpose agent framework, but to develop and share a first-principles understanding of the infrastructure required to operate AI systems reliably.

See [PUBLIC_SAFETY.md](./PUBLIC_SAFETY.md) for confidentiality and data usage guidelines.
